# Yc Weather - Modern Hava Durumu Uygulaması

Yc Weather, anlık hava durumu verilerini estetik bir arayüzle sunan, modern web teknolojileri ile geliştirilmiş bir hava durumu uygulamasıdır. Kullanıcı deneyimini (UX) ön planda tutan **Glassmorphism** tasarım dili ve **responsive** yapısı ile tüm cihazlarda akıcı bir deneyim sunar.

## Öne Çıkan Özellikler

* Otomatik Konum Algılama:** IP veya GPS üzerinden kullanıcının konumunu otomatik bulur.
* Dinamik Arayüz:** Hava durumuna (güneşli, yağmurlu, gece/gündüz) göre değişen arka plan ve atmosferik efektler.
* line_chart: Özel Grafik Motoru:** Harici kütüphane kullanılmadan, saf JavaScript ve SVG ile yazılmış **24 saatlik interaktif sıcaklık ve yağış grafiği**.
* Detaylı Arama:** Şehir bazlı arama ve otomatik tamamlama (Autocomplete) özelliği.
* 7 Günlük Tahmin:** Genişletilebilir kartlar ile haftalık detaylı hava raporu.
* Tamamen Responsive:** Mobil, tablet ve masaüstü uyumlu tasarım.

## Kullanılan Teknolojiler

* Frontend:** HTML5, CSS3, JavaScript (ES6+)
* Styling:** Tailwind CSS (CDN), Custom CSS (Glassmorphism & Animations)
* Icons:** Phosphor Icons
* Veri Kaynağı (API):** * [Open-Meteo API](https://open-meteo.com/) (Hava Durumu Verileri)
    * BigDataCloud & ipapi (Ters Geocoding ve IP Lokasyon)
